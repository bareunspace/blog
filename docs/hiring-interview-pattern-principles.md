# 채용·인터뷰 패턴 콘텐츠 운영 원칙

바른자리의 채용·면접 콘텐츠는 채용공고를 모으는 목적이 아니다. 실제 기업과 기관이 지원자에게 무엇을 직접 수행하도록 요구하는지 관찰하고, 그 평가 방식의 변화에 맞춰 구직자가 무엇을 연습해야 하는지 설명하는 것이 목적이다.

## 핵심 관점

- 질문의 출발점은 `어디가 채용하는가?`가 아니라 `기업이 지원자에게 무엇을 직접 해보라고 하는가?`이다.
- 말하기, PT·발표, 과제 설명, 작업·포트폴리오 설명, 영상·카메라 답변, 상황 대응, 즉석 문제 해결, 토론·롤플레이 등 실제 수행 행동을 우선 관찰한다.
- 개별 공고는 채용정보가 아니라 최근 평가 방식의 변화를 보여주는 데이터 포인트로 취급한다.
- 여러 사례에서 같은 행동이 반복될 때 `최근 채용·인터뷰 패턴`으로 묶어 설명한다.
- 아직 사례가 적거나 한 기업에만 확인된 방식은 전체 시장의 트렌드처럼 단정하지 않는다.

## 바른자리와의 연결 구조

기본 흐름은 다음과 같다.

`공식 전형·공고 확인 → 실제 요구 행동 발견 → 이 사례가 보여주는 평가 변화 해석 → 구직자의 연습 방식 제안 → 말하기·발표·녹화·반복 연습 → 바른자리에서 목적 있는 시간 사용`

바른자리는 면접 학원이나 채용 코칭 서비스가 아니다. 답변의 정답이나 실제 면접 질문을 제공하는 것이 아니라, 지원자가 준비한 내용을 실제로 말하고 설명하고 녹화하며 반복 연습할 수 있는 프라이빗 시간제 공간으로 연결한다.

## 사용자 화면은 설명보다 사례가 말하게 한다

내부 운영 기준은 자세히 유지하되, 사용자 화면에는 필요한 만큼만 보여준다.

- 전체 철학과 관점은 `/cases/`에서 한 번 설명한다.
- 개별 기업 글에서는 `왜 바른자리가 이 사례를 다루는가`를 장황하게 반복하지 않는다.
- 개별 글과 카드에서는 `이 사례가 보여주는 변화`와 `준비 행동`을 1~2문장으로 우선 보여준다.
- 기업과 직무는 당분간 별도 탐색 페이지가 아니라 카드의 분류 정보로만 보여준다.
- `바른자리는 채용정보 사이트가 아닙니다` 같은 문장을 여러 페이지에서 반복하지 않는다.
- 설명으로 설득하기보다 공식 사례와 준비 행동 자체가 의도를 보여주게 한다.

사용자가 이해하면 되는 핵심 흐름은 다음 정도면 충분하다.

`기업이 실제 행동을 요구한다 → 준비도 실제 행동으로 해야 한다 → 말하기·발표·녹화·반복 연습`

## 신규 사례 선정 기준

새 채용공고가 나왔다는 사실만으로 신규 글을 만들지 않는다. 다음 중 하나가 공식 자료에서 분명할 때만 NEW 또는 GROW 후보로 본다.

1. 기존 사례와 다른 새로운 평가 행동이 확인됨
2. 기존 패턴을 강화할 반복 신호가 공식 출처에서 추가 확인됨
3. PT 발표, 과제 후 설명, 포트폴리오 디펜스, 영상 답변, 상황 대응, 토론, 롤플레이, 즉석 문제 해결 등 실제 연습 행동이 구체적으로 요구됨
4. 일정이 임박해 실제 준비 수요가 발생할 가능성이 높음
5. 바른자리의 말하기·녹화·발표·과제 설명 환경과 직접 연결됨

반대로 다음은 SKIP한다.

- 단순 모집 공고
- 모집인원, 연봉, 복지, 기업 소개가 중심인 정보
- 바른자리에서 실제로 연습할 행동이 불분명한 전형
- 이미 충분히 다룬 평가 방식과 사실상 동일한 공고
- 실제 질문, 합격률, 평가 기준을 추정해야만 콘텐츠가 성립하는 경우

## 사례 해석 방식

각 사례에는 가능하면 아래 세 층을 둔다.

- `공개된 전형`: 공식 출처에서 실제 확인된 내용
- `이 사례가 보여주는 변화`: 해당 전형이 어떤 평가 방식의 변화를 보여주는지 제한적으로 해석
- `준비 방향`: 지원자가 실제로 무엇을 말하고, 설명하고, 발표하고, 녹화해볼지 제안

예시:

- 결과물 제출 → 결과물 + 판단 과정 설명
- 짧은 문답 → 과제 수행 + 심층 인터뷰
- 작성형 자기소개 → 카메라 앞 직접 답변
- 예상 질문 암기 → 상황 판단 + 즉시 설명
- 직무 지식 확인 → 문제 정의 + 선택 이유 + 대안 설명

## 글 작성 원칙

- 글의 중심은 채용소식이 아니라 준비 행동이다.
- 제목에 기업명이 들어가더라도 본문은 `이 기업이 뽑는다`보다 `이 전형에서 무엇을 직접 요구하는가`를 먼저 설명한다.
- 개별 글에서는 `이 사례가 보여주는 변화`를 짧게 제시하고 바로 준비법으로 넘어간다.
- 공식 공고에 없는 면접 일정, 예상 질문, PT 발표 여부를 만들어내지 않는다.
- 실제 질문처럼 보이는 문장은 `연습용 질문`임을 명확히 한다.
- 바른자리 소개 비중은 과하지 않게 두고, 문제와 준비법이 먼저 나오게 한다.
- 최종 CTA는 `실제로 말해보기 / 발표해보기 / 녹화해보기 / 반복 연습하기`와 자연스럽게 연결한다.

## 사례 페이지 운영 원칙

- 현재 공개 허브는 `/cases/` 하나로 운영한다.
- 기업명과 직무는 `_data/cases.yml`의 메타데이터로 계속 보존하고 `/cases/` 카드에서 분류 정보로 표시한다.
- 새 `company_slug` 또는 `job` 값이 생겼다는 이유만으로 별도 페이지를 자동 생성하지 않는다.
- 기업별 페이지는 같은 기업에서 서로 다른 검증 사례가 대략 3건 이상 쌓이고, 전형 변화나 평가 행동을 실제로 비교할 가치가 생겼을 때 검토한다.
- 직무별 페이지는 같은 직무의 검증 사례가 대략 3건 이상이고, 최소 2개 이상의 서로 다른 기업·기관에서 반복되는 평가 행동이 확인될 때 검토한다.
- 위 기준에 도달하기 전에는 기업별·직무별 URL을 새로운 공개 콘텐츠로 확장하지 않는다.
- 과거에 만들어진 기업별·직무별 URL은 `/cases/`로 연결하는 호환 경로로만 유지하며 색인 대상에서는 제외한다.
- 각 사례 카드에서는 기업명 자체보다 `이 사례가 보여주는 변화`와 `준비 방향`이 더 중요하다.
- 동일한 패턴의 공고가 반복될 경우 새 글을 무조건 만들지 않고 기존 패턴의 근거를 보강한다.
- 새로운 평가 행동이 반복 확인될 때 별도 패턴으로 승격한다.

## 조사 루틴에 적용

채용 관련 외부 조사는 다음 순서로 판단한다.

`공식 공고 확인 → 실제 요구 행동 추출 → 기존 cases.yml 패턴과 대조 → NEW / GROW / WATCH / SKIP 판정 → 필요 시 기존 글 강화 또는 신규 글 작성`

판정 기준:

- NEW: 기존에 없던 평가 행동이 공식 자료에서 확인됨
- GROW: 기존 패턴을 강화할 반복 근거가 추가됨
- WATCH: 패턴 가능성은 있으나 공식 정보나 반복성이 부족함
- SKIP: 기존과 동일하거나 바른자리의 실제 준비 행동과 연결 가치가 낮음

## 주의

- `최근 채용 트렌드`라는 표현은 반복 신호가 쌓였을 때만 사용한다.
- 한두 사례만 있을 때는 `현재 수집된 사례에서 보이는 변화`, `확인된 사례`, `이 사례가 보여주는 방향`처럼 제한적으로 표현한다.
- 채용시장 전체를 대표한다고 과장하지 않는다.
- 바른자리는 기업 또는 기관과 제휴된 채용 서비스가 아니며, 합격 가능성을 보장하지 않는다.
