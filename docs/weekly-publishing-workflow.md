# 주간 발행 운영 템플릿

이 문서는 블로그를 "계속" 발행하기 위한 실무용 운영 템플릿입니다.
목표는 완성도보다 발행 리듬을 먼저 고정하는 것입니다.

## 1) 주간 운영 캘린더 (고정 슬롯)

- 월요일 30분: 주제 선정 + 우선순위 확정
- 수요일 60분: 1차 발행
- 금요일 60분: 2차 발행 + 성과 기록

주간 최소 목표:
- [ ] 이번 주 발행 1건 이상
- [ ] 다음 주 후보 주제 3개 이상

## 2) 콘텐츠 파이프라인 (3단계)

### Inbox (아이디어)
- 조건: 한 줄 아이디어만 있어도 등록
- 규칙: 생각난 즉시 기록 (2분 이내)

### Draft (초안)
- 조건: 아래 4칸 작성 완료
  - 제목
  - 독자 문제
  - 해결 포인트 3개
  - CTA 1개

### Ready (발행 대기)
- 조건: 메타/이미지/링크 점검 완료
- 조건: 배포 전 스크립트 통과

## 3) 글 1건 발행 SOP (표준 절차)

1. 페이지 생성

```bash
bash scripts/new-page.sh <slug> "<title>" "<description>" --add-sitemap --run-check
```

2. 본문 작성
- 아래 "본문 템플릿"을 복붙해서 작성

3. 빠른 점검

```bash
bash scripts/one-minute-check.sh
```

4. 배포 전 점검

```bash
bash scripts/predeploy-check.sh
```

5. RSS 동기화 필요 시 실행

```bash
bash scripts/sync-naver-blog.sh
```

참고 문서:
- `docs/new-page-quickstart.md`
- `docs/predeploy-checklist.md`

## 4) 본문 템플릿 (복붙용)

```md
# [문제 상황 한 줄]

도입 2~3문장: 누가, 어떤 상황에서, 왜 이 글을 읽어야 하는지.

## 문제 정의
- 현재 겪는 불편 1
- 현재 겪는 불편 2

## 해결 방법
### 1. 첫 번째 방법
핵심 설명 + 바로 실행할 수 있는 액션 1개

### 2. 두 번째 방법
핵심 설명 + 바로 실행할 수 있는 액션 1개

### 3. 세 번째 방법
핵심 설명 + 바로 실행할 수 있는 액션 1개

## 적용 체크리스트
- [ ] 오늘 바로 할 수 있는 항목 1
- [ ] 오늘 바로 할 수 있는 항목 2
- [ ] 오늘 바로 할 수 있는 항목 3

## 마무리 CTA
문의/예약/다음 글 유도 문장 1~2문장.
```

## 5) 금요일 회고 템플릿 (10분)

```md
# 주간 발행 회고 - YYYY-MM-DD

## 실행
- 발행 수:
- 발행 URL:

## 결과
- 조회:
- 클릭(CTA):
- 문의/예약 전환:

## 배운 점
- 잘된 점 1
- 아쉬운 점 1

## 다음 주 실험 1개
- 가설:
- 바꿀 요소(제목/첫문단/CTA 위치 중 1개):
- 성공 기준:
```

## 6) KPI 최소 추적 (3개만)

- 발행 수 (주간)
- CTA 클릭률
- 문의/예약 전환 수

원칙:
- 지표가 떨어지면 한 번에 1개 요소만 수정
- 제목, 첫 문단, CTA 위치 순서로 우선 개선

## 7) 운영 실패 방지 규칙

- "발행 못한 주"가 생기면 다음 주 목표를 1건으로 낮춰 재시작
- 2주 연속 밀리면 글 길이를 절반으로 줄여 리듬 복구
- 완성도 70%에서 발행, 나머지는 다음 패치에서 개선
