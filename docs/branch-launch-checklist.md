# 지점 오픈 체크리스트 (본사 미확정 공용)

## 1) 기본 정보
- [ ] 지점명 확정
- [ ] slug 확정 (영문 소문자 + 하이픈)
- [ ] 주소/전화/이메일 등록
- [ ] 운영시간/마감예약시간 등록

## 2) 예약/문의
- [ ] 예약 링크 연결
- [ ] 지도 링크 연결
- [ ] 상담 채널 링크 연결
- [ ] 문의 폼에 지점 선택값 추가

## 3) 콘텐츠
- [ ] 대표 이미지 1장 등록
- [ ] 갤러리 이미지 최소 6장 등록
- [ ] 지점 소개 문구 3문단 작성
- [ ] 지점 고유 FAQ 3개 작성
- [ ] SEO 문구에는 지역명 + 공간대여/스터디룸/회의실/화상면접/상담실 등 검색어가 포함되었는지 확인
- [ ] 브랜드 문구에는 "나만의 시간을 예약하세요"와 "개인시간 플랫폼" 기준이 반영되었는지 확인

## 4) SEO
- [ ] 지점별 title/description 작성
- [ ] canonical URL 지정
- [ ] og:image 설정
- [ ] LocalBusiness JSON-LD 생성
- [ ] sitemap 포함 여부 확인

## 5) 트래킹
- [ ] branchSlug 포함 이벤트명 적용
- [ ] 예약 버튼 클릭 이벤트 확인
- [ ] 문의 전송 이벤트 확인
- [ ] 모바일 고정 CTA 이벤트 확인

## 6) 품질 점검
- [ ] 모바일(360px) 레이아웃 확인
- [ ] 주요 링크 정상 동작 확인
- [ ] 폼 제출/응답 확인
- [ ] 오탈자/가격/시간 재검수

## 오픈 승인 기준
- 위 항목 중 필수(1~4, 6) 모두 완료 시 공개 가능
- 트래킹(5)은 최소 예약/문의 이벤트 확인 시 공개 가능
