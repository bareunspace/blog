# 바른자리 사이트 전체 성장 최적화 — 2026-08-11

## 목표
검색 유입 → 목적별 허브 → 실제 공간 이해 → 빈 시간 확인 → 예약으로 이어지는 흐름을 강화한다. 바른자리를 단순 공간대여가 아니라 **방해받지 않는 개인시간과 목적 있는 시간을 예약하는 공간**으로 일관되게 표현한다.

## 이번 변경의 핵심

### 1. SEO / AIO 검색 의도 정렬
- 홈: `부천 공간대여`, `신중동 공간대여`, `부천 스터디룸`, `부천 미팅룸`, `시간제 사무실`을 자연스럽게 통합.
- 면접 허브: `부천 면접 연습 공간`, `화상면접 장소`, `말하기·녹화 리허설` 중심.
- 미팅·업무 허브: `부천 미팅룸`, `시간제 사무실`, `프리랜서 업무공간`, `1인사업자 미팅` 중심.
- 스터디 허브: `부천 스터디룸`, `대학생 팀플 장소`, `프로젝트`, `발표·토론` 중심.
- 연습 허브: `부천 연습실`, `셀프테이프 촬영`, `오디션 리허설` 중심.
- 프라이빗시간 허브: `부천 프라이빗 공간`, `개인시간`, `둘만의 대화`와 브랜드 철학을 연결.

### 2. 홈 Hook 개선
기존의 추상적인 `나만의 시간을 예약하세요`를 유지하는 철학 위에 실제 구매 이유를 더 명확히 제시한다.

핵심 메시지:
> 오늘 필요한 시간을, 방해받지 않게 예약하세요.

공간 자체보다 `그 시간에 끝내야 할 일`을 먼저 보여주도록 변경한다.

### 3. 운영시간 전체 수요 설계
운영시간 07:00~23:00을 하나의 수요로 보지 않고 시간대별 고객 상황으로 나눈다.

| 시간대 | 우선 수요 | 연결 허브 |
|---|---|---|
| 07:00~12:00 | 프리랜서·1인사업자 집중업무, 상담, 화상회의 | 미팅·업무 |
| 12:00~17:00 | 화상면접, 발표·스피킹, 온라인 일정 | 면접 / 연습 |
| 17:00~21:00 | 대학생 팀플, 프로젝트, 스터디·소모임 | 스터디·소모임 |
| 21:00~23:00 | 개인 작업, 정리, 독서, 조용한 대화 | 프라이빗시간 |

홈에 이 시간대별 진입 구조를 추가해 비인기 시간도 별도의 사용 이유를 갖도록 한다.

### 4. 예약 전환
- Hero CTA를 `오늘 빈 시간 확인하기`로 구체화.
- 목적별 카드에서 공간 기능보다 사용자가 해결하려는 일을 먼저 설명.
- 사진 → 목적 허브 → 예약 흐름을 유지.
- 허위 희소성, 가짜 후기, 근거 없는 성과 수치 없이 실제 시설·요금·운영 방식만 사용.

### 5. 바른자리 철학
`프라이버시는 이제 돈으로 사는 가치입니다`와 `개인시간`을 장기 브랜드 축으로 유지한다. 다만 모든 방문자에게 추상적인 철학부터 요구하지 않고, 검색자가 가진 실제 문제에서 시작해 마지막에 **방해받지 않는 시간을 예약한다**는 철학으로 연결한다.
