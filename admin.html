오늘 이용 0

오늘 실제 이용 예정인 확정 예약입니다.

1. 신청부터 확인

신청 탭에서 상태를 바꾸고 필요한 메모를 남긴 뒤, 운영할 건만 다음 단계로 넘깁니다.

2. 모임으로 전환

신청 카드에서 바로 모임 초안을 만들고, 제목과 일정만 빠르게 정리합니다.

3. 운영 정보 정리

모임 탭에서 오픈채팅 링크와 상태를 다듬고, 필요하면 원본 신청으로 다시 돌아갑니다.

4. 확정 예약 확인

예약 원장 탭에서 네이버 확정/취소 예약과 결제 정보를 시간순으로 확인합니다.

Reports

신고 큐

사용자 신고는 필요할 때만 펼쳐 확인합니다.

열기

관리자 인증 후 신고 목록을 불러옵니다.

Workspace

커뮤니티 운영 워크스페이스

신청 검토와 모임 운영을 분리해 지금 하는 일만 보이도록 정리했습니다.

Applications

커뮤니티 신청

사이트에서 들어온 신청을 검토하고, 필요한 경우 운영용 모임으로 전환합니다.

Workflow

신청 검토 순서

  1. 새 신청만 골라 현재 확인할 건부터 봅니다.
  2. 상태를 먼저 바꾸고, 필요한 경우에만 상세 수정 패널을 엽니다.
  3. 운영할 신청이면 바로 모임 초안 만들기로 넘깁니다.

신청 내용 수정

관리자 인증 후 신청 목록을 불러옵니다.

Groups

모임 관리

운영할 모임만 모아 일정, 상태, 안내 링크를 정리합니다.

Operations

모임 운영 순서

  1. 운영할 신청만 모임 초안으로 전환합니다.
  2. 제목, 일정, 오픈채팅 링크를 먼저 채워 공지 가능한 상태로 만듭니다.
  3. 원본 신청이 필요한 경우 카드에서 바로 다시 엽니다.

새 모임 만들기

대표 이미지는 1장만 업로드합니다.

선택된 이미지 없음

파일 업로드 시 브라우저에서 WebP 변환 후 업로드합니다. 1장 기준 500KB로 자동 압축합니다.

    확정 예약 원장

    Supabase reservations 테이블의 네이버 예약을 시작시간순으로 조회합니다. 기존 예약 요청은 신청 검토 화면에 그대로 둡니다.

    Reservations

    확정 예약 원장

    1. 네이버에서 들어온 확정 예약과 취소 예약을 따로 확인합니다.
    2. 오늘/내일 예약을 먼저 보고, 전체 또는 날짜별로 좁혀 봅니다.
    3. 예약번호 검색으로 Zapier 연동 내역을 빠르게 찾습니다.

    관리자 인증 후 예약 원장을 불러옵니다.
