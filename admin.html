Admin Dashboard

관리자 인증 완료

오늘 처리할 신청을 먼저 보고, 필요하면 모임으로 전환해 운영까지 이어서 관리하는 화면입니다.

  • 먼저 신청을 검토하고, 운영할 건만 모임으로 넘기는 흐름에 맞췄습니다.
  • 신청과 모임이 연결되어 있으면 서로 바로 열어볼 수 있습니다.
  • 관리자 권한 체크는 이메일 허용 목록과 Supabase 로그인 세션을 함께 검증합니다.

Overview

운영 현황 한눈에 보기

지금 바로 손봐야 할 신청과 운영 중인 모임 수를 먼저 확인합니다.

바로 확인할 신청 0

새 신청과 검토 중 상태를 합친 수입니다.

아직 안 본 새 신청 0

먼저 열어봐야 하는 신규 신청입니다.

등록된 모임 0

준비 중, 운영 중, 종료된 모임 전체 수입니다.

지금 운영 중인 모임 0

모집 중 또는 일정 확정 상태의 모임입니다.

1. 신청부터 확인

신청 탭에서 상태를 바꾸고 필요한 메모를 남긴 뒤, 운영할 건만 다음 단계로 넘깁니다.

2. 모임으로 전환

신청 카드에서 바로 모임 초안을 만들고, 제목과 일정만 빠르게 정리합니다.

3. 운영 정보 정리

모임 탭에서 오픈채팅 링크와 상태를 다듬고, 필요하면 원본 신청으로 다시 돌아갑니다.

Reports

신고 큐

사용자 신고를 빠르게 확인하고, 필요하면 모임을 즉시 삭제하거나 처리 상태를 변경합니다.

관리자 인증 후 신고 목록을 불러옵니다.

Workspace

커뮤니티 운영 워크스페이스

신청 검토와 모임 운영을 분리해 지금 하는 일만 보이도록 정리했습니다.

Workflow

신청 검토 순서

  1. 새 신청만 골라 현재 확인할 건부터 봅니다.
  2. 상태를 먼저 바꾸고, 필요한 경우에만 상세 수정 패널을 엽니다.
  3. 운영할 신청이면 바로 모임 초안 만들기로 넘깁니다.

Applications

커뮤니티 신청

사이트에서 들어온 신청을 검토하고, 필요한 경우 운영용 모임으로 전환합니다.

신청 내용 수정

관리자 인증 후 신청 목록을 불러옵니다.

Operations

모임 운영 순서

  1. 운영할 신청만 모임 초안으로 전환합니다.
  2. 제목, 일정, 오픈채팅 링크를 먼저 채워 공지 가능한 상태로 만듭니다.
  3. 원본 신청이 필요한 경우 카드에서 바로 다시 엽니다.

Groups

모임 관리

운영할 모임만 모아 일정, 상태, 안내 링크를 정리합니다.
