How It Works

신청부터 만남까지 이렇게 진행돼요

처음부터 모임장이 없어도 괜찮습니다. 관심자가 먼저 모이면 그중에서 진행할 사람을 정하고 일정을 맞춥니다. 모임장과 일정이 정해진 뒤에 바른자리 공간을 예약합니다.

모임 찾기

관심 있는 모임을 보고 참가 또는 관심 신청을 남깁니다.

신청 확인

바른자리에서 신청 내용을 확인하고 모임 진행에 필요한 정보를 정리합니다.

최소 인원 확인

함께할 사람이 모이면 가능한 일정과 진행 방식, 모임장을 함께 정합니다.

공간 예약

모임장과 일정이 정해지면, 모임장이 기존 예약 채널에서 바른자리 공간을 예약합니다.

오픈채팅 안내

확정된 참가자에게만 소통 채널과 세부 일정을 안내합니다.

함께 준비

정해진 시간에 모여 서로의 준비와 관심사를 편안하게 나눕니다.

Principles

운영 원칙

역할 분리

바른자리는 관심자를 모으고 공간 이용을 안내합니다. 실제 운영은 확정된 모임장이 담당합니다.

기존 모임도 가능

이미 운영 중인 모임도 바른자리에서 만나고 싶다면 등록할 수 있습니다. 단, 기존 참가자 안내와 운영은 모임장이 담당합니다.

예약 분리

모임장과 일정이 정해진 뒤, 모임장이 기존 예약 채널에서 바른자리 공간을 직접 예약합니다.

개인정보 보호

연락처와 오픈채팅 링크는 공개 페이지에 노출하지 않고, 확정된 절차 안에서만 안내합니다.

성과 보장 없음

바른자리는 면접 코칭, 답변 첨삭, 합격 보장 서비스를 제공하지 않습니다.
